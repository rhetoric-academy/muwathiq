خطوات النشر على GitHub Pages
1) أنشئ مستودعاً جديداً على GitHub وارفع كل محتويات هذا المجلد (index.html و manifest.json و sw.js ومجلد icons).
2) من Settings ثم Pages اختر Branch: main و Folder: /(root) ثم Save.
3) افتح الرابط الذي يظهر (https://USERNAME.github.io/REPO/) ثم ثبّت التطبيق:
   - أندرويد/ويندوز/ماك (Chrome أو Edge): أيقونة التثبيت أو القائمة ثم "تثبيت التطبيق".
   - آيفون (Safari): مشاركة ثم "إضافة إلى الشاشة الرئيسية".
عند تعديل الملفات لاحقاً غيّر رقم CACHE في sw.js (مثلاً muwathiq-v2) ليصل التحديث للمستخدمين.
